# CAD 軟體評估：CADCraft、ZWCAD 與 AutoCAD

比較開源 CAD 軟體 CADCraft、商業替代方案 ZWCAD 與 AutoCAD 的功能差異及可用性風險。單一 HTML 網頁，室內設計風格，以底部按鈕選單翻閱。

**線上瀏覽**：https://chengshunyi.github.io/cad-compare/

## 內容

1. 總覽
2. CADCraft 概況
3. CADCraft 功能比較
4. CADCraft 可用性風險
5. CADCraft 適用情境與試用方法
6. ZWCAD 與 AutoCAD 比較及風險
7. 三方定位、結論與資料來源

## 操作

- 底部選單切換頁面，或用 ‹ › 按鈕、鍵盤左右方向鍵翻頁
- 每頁有獨立網址（例如 `#zwcad`）可直接分享
- 支援手機與深色模式

## 注意

資料截至 2026-11-24。CADCraft 版本更新快速，ZWCAD 部分數據為廠商自述；風險程度為一般設計事務所情境下的判斷，非資料來源評等。
