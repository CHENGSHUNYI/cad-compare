CADCraft

CADCraft 是什麼

用 Rust 從零重寫的開源 CAD，操作流程仿照 AutoCAD。免費，不需帳號也不用訂閱。

開發者
ArtCraft 團隊

GitHub：storytold/cadcraft

授權
MIT 或 Apache-2.0

DWG 函式庫 acadrust 為 MPL-2.0

平台
Windows、macOS、Linux

另有 FreeBSD 與瀏覽器版

狀態
Pre-alpha

評測引用版本 0.20.1（2026-11-12）

38%

專案自評「可用於實際工作」的程度

AutoCAD 選單指令約 50% 已有對應；3D 約 2%（專案自評，2026-10）。評測估計距離 alpha 還需約 125–190 個代理工時。

CADCraft 與 AutoCAD

功能逐項比較

2D 繪圖已有雛形，但 3D、DWG 寫入、動態圖塊與 DCL 都還差得遠。

繪圖與檔案

CADCraft

可用性風險

最大的問題是資料安全：存檔可能遺失內容，輸出的 DWG 也沒經過 AutoCAD 驗證。

風險程度：高

存檔可能遺失資料

官方 README 明說：尚未建模的物件，存檔時不會保留。代理物件與自訂物件會被丟棄。

緩解：0.15.1 起覆蓋存檔前會警告，可產生 .bak 備份。

風險程度：高

DWG 交換不可靠

寫入只支援 R2000，測試多用合成檔案。一個 10 MB 實際檔案約 2 分鐘仍開不起來（issue #57）。

緩解：交付前一律用 AutoCAD 開啟比對。

其他風險

風險說明程度
LISP 相容用到 DCL 或 vla-／vlax- 函式的程式多半無法執行高（自製工具）
商業支援沒有廠商支援與相容性保證高（正式案件）
幾何精度橢圓、雲形線以線段近似，交點與偏移不精確中
版本變動一個月內未解 issue 從 104 增至 650，程式會自動更新中
本機安全連上 MCP 的 AI 代理可讀寫使用者能存取的所有檔案中

程度依一般設計事務所的使用情境判斷，不是資料來源的評等。

CADCraft

適用情境與試用方法

可以拿來學習、教學和做自動化實驗；正式出圖與交換圖檔，現階段留在 AutoCAD。

適合

  • 個人學習與簡單 2D 草圖
  • Linux 或瀏覽器環境
  • 用 AI 代理自動繪圖的實驗
  • 零授權成本的教學示範

不建議

  • 正式案件與合約交付
  • 與業主、協力廠商往來 DWG
  • 需要 3D、動態圖塊或圖紙集
  • 依賴 DCL 對話框的 LISP 工具

如果要試，這樣做

1

只開副本

原檔不動，在副本上作業，並開啟 .bak 備份。

2

回到 AutoCAD 比對

存檔後用 AutoCAD 開啟，檢查圖塊、外部參考與標註是否完整。

3

先測 LISP 工具

逐支執行常用程式，記下 DCL 與 vla- 函式的失敗點。

ZWCAD

ZWCAD 與 AutoCAD

商業授權的 AutoCAD 相容 CAD，主打原生 DWG、相近介面與永久授權。不少數據來自廠商自己的說法。

開發商
中望軟體 ZWSOFT

總部位於中國廣州

授權
永久授權

官網標價 US$899 起

檔案
原生 DWG

直接讀寫，不需轉檔

開發介面
LISP、VBA、ZRX、.NET

各版本支援範圍不同

功能比較

項目ZWCADAutoCAD
DWG原生讀寫；獨立評測顯示基本物件一致原生格式
動態圖塊Flexiblock 可開啟、編輯（廠商說法）完整
LISP 與 APIAutoLISP、VBA、ZRX、.NET；.NET 專案可移植完整
2D 效能廠商自測 2D 操作快 1.98 倍基準

可用性風險

風險說明程度
採購規範中國大陸廠牌軟體；公務機關與政府案件可能受使用限制，請依機關或業主規定確認高（公部門案件）
動態圖塊2026-03 論壇回報：重開檔後動態圖塊被改名、失去功能高（大量使用者）
已編譯程式AutoCAD 的 .fas／.vlx、ObjectARX 外掛需原始碼或重新編譯（一般經驗，請實測）中

資料來源效能與相容性數據多為廠商自測，缺少獨立驗證中

結論

三套軟體的定位

CADCraft 拿來試，ZWCAD 拿來省，AutoCAD 拿來交件。

開源試用

CADCraft

免費、跨平台、可接 AI 代理；pre-alpha，存檔會遺失資料，只適合學習與實驗。

低成本替代

ZWCAD

原生 DWG、永久授權；動態圖塊與已編譯外掛需實測，公部門案件先確認規範。

業界標準

AutoCAD

相容性與生態系最完整；訂閱成本最高，是正式交付最穩妥的選擇。
